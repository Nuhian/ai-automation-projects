# AI & Automation Projects

Self-initiated automation projects built using no-code/low-code tools and AI APIs to solve real business workflow problems.

## Projects

### 1. AI Lead Triage System
Automated system to receive incoming leads, classify them by intent/priority using AI, and route them to the appropriate next step — reducing manual review time.
- **Tools:** Make.com, OpenAI/Gemini API
- **Key skills:** workflow design, API integration, prompt engineering, conditional logic

### 2. AI Inbox Sorting Assistant
An automation that monitors an email inbox, uses AI to classify incoming messages by category/urgency, and organizes them automatically — reducing manual sorting effort.
- **Tools:** Make.com, OpenAI/Gemini API
- **Key skills:** email automation, AI classification, workflow orchestration

### 3. Automated Invoice Processing
Workflow that automates the extraction and processing of invoice data, reducing manual data entry.
- **Tools:** Make.com
- **Key skills:** data extraction, process automation

## Background
MIS (Management Information Systems) background with hands-on, self-taught experience in no-code automation platforms and AI API integration. Comfortable designing end-to-end automated workflows from problem definition to deployment.
